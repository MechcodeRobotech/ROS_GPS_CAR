ใช้งานยังไง / How to use

  1. ดูว่าปลอดภัยไหม — แถบบนต้องเป็นสีเขียว: เชื่อมต่อ ปกติ · GPS มีดาวเทียม · แบตเตอรี่เกิน 10.8 V
    Check the top bar is green before driving.
  2. ลองขับเอง — หน้าหลัก → “ขับเอง” กดลูกศรค้างไว้ ปล่อยแล้วหยุด (คีย์บอร์ด W A S D · Space = หยุด)
    Hold an arrow to drive, release to stop.
  3. สั่งให้วิ่งเอง — หน้า “แผนที่” คลิกจุดที่ต้องการ → “ไปที่นี่เลย” หรือหน้า “จุดหมาย” ใส่รายการแล้วกดปุ่มเขียวหน้าหลัก
    Click the map and choose “Go here”, or build a waypoint list.
  4. หยุดฉุกเฉิน — ปุ่มแดงมุมขวาบน กดได้ตลอดทุกหน้า ปุ่มเห็ดบนตัวหุ่นยังตัดไฟจริงเสมอ
    The red button always works, on every page.
